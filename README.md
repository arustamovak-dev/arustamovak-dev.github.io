# Екатерина Батина — портфолио

Сайт: https://arustamovak-dev.github.io/

Персональный сайт продуктового дизайнера. Статический HTML, CSS и JavaScript, без сборки и сторонних зависимостей.

## Локальный просмотр

Откройте `index.html` в браузере. Все изображения, анимации и резюме включены в репозиторий.

## Структура

- `index.html` — содержимое страницы и кейсов.
- `styles.css` — оформление и адаптивная верстка.
- `script.js` — меню, модальные окна и анимации.
- `interaction-cursor.js` — подсказка рядом с курсором.
- `photo-stack/` — интерактивная стопка фотографий.
- `images/` — обложки, логотипы и изображения кейсов.
- `documents/` — резюме для скачивания.

## GitHub Pages

Сайт можно публиковать из корня основной ветки репозитория. Файл `.nojekyll` отключает обработку Jekyll. Изменения сайта вступают в силу после отправки файлов в GitHub и завершения публикации Pages.
